Keyboard shortcuts

⌘NNew note
⌘FSearch notes
⌘⌥↑ / ↓Previous / next note
⌘⇧PPin / unpin note
⌘⌫Delete note (with undo)
⌘B ⌘I ⌘UBold / italic / underline
⌘⇧XStrikethrough
⌘8 / ⌘7 / ⌘9Bullet / numbered / checklist
⌘⇧1–3 , ⌘⇧0Heading 1–3 / plain text
Tab / ⇧TabIndent / outdent list item
⌘⇧DInsert a date
⌘KAdd link to selection
⌘Z / ⌘⇧ZUndo / redo
⌘/This panel

Type as you write

- then spaceStarts a bullet list
1. then spaceStarts a numbered list
[] then spaceStarts a checklist (click the box to tick)
@dateOpens a date picker and inserts a date chip (click a chip to change it)
@today / @tomorrowInserts that date straight away
# / ## then spaceHeading
